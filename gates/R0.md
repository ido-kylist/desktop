# Gate R0 — rehearsal

**Verdict: PASSED** · 2026-11-14 · phase D0.5

One throwaway feature (`scratch.wordCount`, protocol v1→v2) taken end to end:
brief → worker → independent review → merge through branch protection → revert.

## Findings (the point of the exercise)

1. **The brief's file allowlist was too tight.** It excluded a new file under `src/shared/`,
   which forced the pure `countWords` function into `ipc-contract.ts` — a schema module now
   carrying logic. The worker flagged it and justified it correctly, but the brief was wrong.
   *Rule for future briefs: an allowlist must permit at least one new module in the area
   being changed.*

2. **Protocol version literals in tests are brittle.** Bumping to v2 broke two existing e2e
   assertions that hardcoded the string `protocol v1`. The worker changed only the literal,
   which is correct — but a version bump should not require touching unrelated tests.
   *D1: assert `v${window.cleon.protocolVersion}` instead of a hardcoded number.*

3. **A typed bridge cannot exercise its own error branch.** The renderer's `ok: false` path
   is unreachable through the UI, because a correctly typed `invoke` cannot produce a
   malformed payload. It is implemented and typed, and the failure path is covered at the
   IPC boundary, but the *rendered* error state has no automated test.
   *D1: add a fault-injection channel behind a dev flag so error states are testable.*

4. **Green first time is not the same as reviewed.** The worker reported all checks passing;
   re-running them independently took ~90 s and confirmed 17/17 unit and 3/4 e2e (1 skipped
   by design). Verify anyway — the cost is trivial and the report is not evidence.

5. **e2e silently tests the previous build.** Playwright launches `out/`, not `src/`. After
   reverting the feature, the suite failed until `pnpm build` ran — it was asserting against a
   stale bundle that still spoke protocol v2. CI builds first, so this only bites locally, but
   it means a green local e2e run proves nothing about uncommitted source. *Always build
   before trusting e2e results by hand.*

## Disposition

The feature is deleted in the same PR that records this log — it was disposable by design.
The revert also returns `PROTOCOL_VERSION` to 1, because the channel never shipped: the
contract surface is identical to v1, and a version number that outlives its own surface is
just noise. **The next real channel change goes to v2** — and it must also fix finding 2,
so the bump stops breaking unrelated assertions.
