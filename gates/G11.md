## Deliberate omissions, stated not hidden

- **Unsigned and unnotarized.** No Developer ID certificate exists. `xattr -dr com.apple.quarantine`
  is documented in the README and the release notes. No signature was faked.
- **Tag-triggered publishing is disabled** until the arm64 cross-build from an x64 runner is
  observed green once. Publishing 0.1.0 was manual and verified locally. A tag push that
  silently fails to publish would be worse than a manual step.
- **The chat is proven against the bundled mock.** No paid provider has been called; that needs
  an owner credential and no code change.

## What this release actually is

A local-first chat client where the differentiators work and the extras do not exist:
branching with variants that survive relaunch, FTS5 history search in the main process,
per-message cost meters read from persisted rows, and an error taxonomy that refuses to
disguise a failure as an answer. Attachments, native shell, assistants, MCP and RAG are cut
and recorded in `BACKLOG.md`.
