### What this release contains beyond 0.1.0

Provider settings (key, base URL, model catalogue) · attachments with caps and distinct
refusals · native shell (`⌥Space` launcher, tray, `cleon://`, notifications) · projects,
assistants and a prompt library with variable expansion · MCP over stdio with per-call
approval, containment and a kill switch · knowledge ingestion with citation chips ·
versioned artifacts.

### Numbers behind it

`threads.list` p95 **0.65 ms**, FTS search p95 **6.91 ms**, `chat.thread` p95 **0.17 ms**
against 500 threads × 10 messages (`PERF.md`). Soak: 30 minutes, **10,825 turns**, 43,300
deltas, zero crashes, zero leaked bus listeners, RSS plateau ~200 MB (`docs/SOAK.md`).
axe clean on five screens; keyboard-only conversation test green. **475 unit/integration,
26 e2e, 2 packaged.**

## Deliberate omissions, stated not hidden

- **Unsigned and unnotarized.** No Developer ID certificate. `xattr -dr com.apple.quarantine`
  documented in the README and the notes. No signature was faked.
- **Tag-triggered publishing stays disabled** until the arm64 cross-build from an x64 runner is
  observed green once. Both releases were built and verified locally.
- **The chat is proven against the bundled mock and against the real Sciforium endpoint** for
  transport, streaming, catalogue and key storage — but no paid turn has been run since the
  deployment-prefix quirk was found (`docs/DECISIONS.md`).
- **No notarization, no pentest, no profiler trace, no Windows/Linux build.**

## Honest summary

Two releases in one weekend, both installed and exercised from the DMG rather than the dev
build. The features that carry the product's claims — branching, honest cost, per-call tool
approval, local-first storage — work and are tested. What is missing is written down in
`BACKLOG.md` rather than implied by silence.
